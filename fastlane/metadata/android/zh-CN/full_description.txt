AgePony 是一款快速、注重隐私的手机加密应用，基于现代的 age 加密格式。加密你的文件和消息，只让对的人打开；为它们签名，让收件人确认文件确实出自你手；密钥和数据都留在你自己的设备上。无需账号，没有跟踪，没有统计分析。

抗量子加密
防范“先收集、后解密”的攻击。AgePony 可以生成抗量子的混合密钥（ML-KEM-768 与 X25519 结合），即使面对未来的量子计算机也能保持安全，同时与 age 命令行工具完全兼容。凡是加密给抗量子收件人的内容都会有明显标记，你随时都清楚自己用的是哪种保护。

此外还有：
- 一步完成加密和签名，收件人既能打开文件，也能确认文件确实来自你。
- 内置迁移工具，可将旧文件升级为抗量子加密。批量将现有文件重新加密给新的抗量子密钥，新副本验证通过之前，原文件都会保留。

为什么选择 AgePony
- 标准的 age 加密。AgePony 读写的格式与 age 命令行工具完全相同，你的文件在电脑和服务器上的其他 age 工具中同样可用。
- 公钥或密码短语。可以加密给对方的公钥，也可以用密码短语加密文件，再另行告诉对方密码短语。
- 规范的 SSH 签名。在“文件”标签页中，使用 SSH Ed25519 或 RSA 密钥、硬件密钥，或通过 NFC 使用安全密钥，为文件签名和验证签名，并维护一份受信任的签名者列表。签名采用 SSHSIG 标准，ssh-keygen 可以直接验证。
- 默认在本机完成。加密、解密、签名和密钥生成全部在手机本地进行，私钥绝不会离开你的设备。
- 只有一个可选的联网步骤。从 GitHub 导入收件人时，AgePony 会从 github.com 获取对方的 SSH 公钥。这是应用唯一的网络请求，只在你点按“获取”时发生，不会发送任何关于你的信息。
- 无跟踪、无广告、无需账号。AgePony 不收集统计数据或个人信息。
- 开源。完整源代码公开，可供审查。

功能
- 生成 age 密钥对并保存在应用的保险库中，用设备的生物识别解锁。
- 抗量子混合密钥（ML-KEM-768 + X25519），也支持传统的 X25519 密钥。
- 加密和解密文件及文本消息。
- 密码短语加密，无需密钥即可快速分享。
- 使用 SSH Ed25519 或 RSA 密钥、硬件密钥，或通过 NFC 使用安全密钥，为文件签名和验证签名（SSHSIG），并支持受信任的签名者列表。
- 可用生物识别、密码或 PIN 码解锁，即使手机没有设置屏幕锁定也能使用。
- 可选的胁迫密码，输入后会清空保险库。
- 用相机扫描二维码添加收件人密钥。
- 通过 GitHub 用户名导入收件人，从 github.com 获取其 SSH 公钥。
- 批量将现有文件迁移为抗量子加密。

无论你是记者、社会活动人士、开发者，还是只想真正掌控自己私密文件的普通人，AgePony 都能为你提供强大的标准加密，而且用起来不复杂。

AgePony 是基于开放的 age 加密格式开发的独立应用，与 age 项目没有关联。
