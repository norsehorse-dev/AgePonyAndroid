AgePony 5.0.1 (security release)

- A duress PIN now makes the vault PIN-only
- Vault locks after using the share sheet
- No lock with a password now asks for it
- Waits after wrong PINs, optional erase after 10
- Screenshots and Recents blocked by default
- Key transfer: confirm a code on both phones
- Signatures bind recipients and file name
- allowed_signers restrictions enforced
- Failed decrypts leave no partial file
- Stricter checks on crafted files
